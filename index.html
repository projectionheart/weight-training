Why does the image keep changing?

LiveGrid changes the noise supplied to the model. A new prompt changes the conditioning too. The same learned weights process these changing inputs; successive images are then blended into video.

Is that a video model?

No. SD-Turbo generates images. LiveGrid’s evolving noise and blending create movement, but do not guarantee a character stays consistent or motion follows real-world physics.

Download size ≠ GPU memory

Weights are only part of memory use. Intermediate tensors, image size, batches, framework overhead, and other software also consume VRAM. This calculator is not a GPU compatibility test.

100 squares ≠ 100 models

LiveGrid loads one model, generates one stream, and arranges its output into 100 cells. It does not multiply model-weight storage by 100. The copy slider models separate loaded instances, not grid cells.

What does fp16 mean?

A floating-point format represents a range of numbers using a finite number of bits. fp16 uses 16 bits—two bytes—per value. fp32 uses four bytes. Lower precision reduces storage, but rounding can affect numerical behavior. Converting to 8-bit requires suitable quantization methods and compatible software; selecting it here does not convert or modify your files.
